01

프로젝트 개요

스도쿠는 규칙이 단순하면서도 논리적 사고력을 기르는 데 효과적인 퍼즐이다. 이 프로젝트는 학생이 혼자서도 꾸준히 도전할 수 있는 웹 기반 스도쿠 게임과, 교사가 반 전체의 참여도와 실력 추이를 파악할 수 있는 대시보드를 한 세트로 구축하는 것을 목표로 한다.

  • 목적 — 수업 전후 자투리 시간이나 과제용으로 활용 가능한 자가 학습 도구 제공
  • 대상 — 별도 로그인 없이 이름만으로 참여하는 학생, 결과를 확인하는 교사
  • 핵심 가치 — 진입장벽 없는 시작, 난이도의 세분화, 교사 관점의 가시성
02

핵심 기능

학생용

플레이 화면

  • 이름 + 학급 + 아바타 이모지 선택 후 바로 시작 (회원가입 없음)
  • 첫 방문 시 규칙 설명(Lv.0) 1회 안내, 학습 사다리는 '연습' 탭에서 진행
  • 난이도 4단계 — 쉬움 / 보통 / 어려움 / 전문가, 처음부터 모두 개방
  • 게임 화면 안의 난이도 탭으로 즉시 전환 + 옆에 '이 난이도 우리 반 TOP 5'
  • 난이도별 랭킹 — 보정 기록(시간 + 실수×10초 + 힌트×30초) 기준
  • 콤보·별점(1~3개)·완료 축하 효과·숫자별 남은 개수 표시로 몰입 유도
  • 9×9 보드, 숫자패드 또는 키보드 입력
  • 경과 시간 타이머, 실수 횟수 카운터, 힌트
  • 완료할수록 쌓이는 레벨·경험치(XP)·뱃지
  • 재방문 시 이전 기록을 이어서 성장
교사용

대시보드

  • 교사 전용 접속 화면 — 상단 메뉴 '🧑‍🏫 교사'에서 진입(비밀번호 1개로 간단 보호)
  • 학생별 전체 풀이 기록 목록 (이름·날짜·난이도순 정렬)
  • 난이도별 평균 소요 시간·완료율 통계
  • 학생 개인 리포트 — 시도 추이, 힌트 의존도, 레벨 성장
  • 학습 단계 일괄 지정 — 학급 전체를 같은 보드 크기·레벨로 시작
  • 학급별 랭킹 보드 — 종합(XP) + 난이도별 탭, 공개 범위 설정 가능
  • 기간/난이도 필터링, CSV로 내보내기
03

사용자 흐름

학생 흐름

STEP 1이름 + 학급 입력이름과 반을 입력하면 기존 기록이 있으면 자동으로 이어받음
STEP 2(처음이면) 규칙 알아보기교사가 일괄 지정했으면 그 보드 크기·레벨로 바로 시작, 아니면 규칙 설명 1회 후 게임 화면으로
STEP 3게임 화면에서 난이도 탭으로 풀이[연습 · 쉬움 · 보통 · 어려움 · 전문가] 탭을 언제든 전환, 옆 패널에서 이 난이도 반 TOP 5 확인
STEP 4결과 저장 · 성장XP·레벨 누적, 별점·최고 기록 갱신 여부와 이 난이도 반 순위 표시, 교사 대시보드에 반영

교사 흐름

STEP 1대시보드 접속간단한 접속 코드 또는 비밀번호 입력
STEP 2 · 선택학습 단계 일괄 지정오늘 수업에서 전체 학생이 시작할 보드 크기·레벨을 지정 (지정 안 하면 학생 자율 선택 유지)
STEP 3전체 현황 · 랭킹 확인참여 학생 수, 난이도 분포, 학급별 랭킹 보드 요약
STEP 4학생별 상세 조회이름 클릭 시 개인별 시도 이력과 추이 확인
STEP 5내보내기필요 시 CSV로 다운로드해 평가·상담 자료로 활용
04

단계별 학습 설계

처음 스도쿠를 접하는 학생은 규칙을 모른 채 빈 보드와 마주하면 바로 이탈하기 쉽다. 첫 방문자에게는 아래 학습 사다리를 자동으로 안내하고, 완료 기준을 통과하면 다음 단계가 자연스럽게 해금되도록 한다. 연습 단계는 4×4(2×2 박스, 최소 단위)·6×6(2×3 박스, 입문용)·9×9(표준) 세 가지 보드 크기 중 고를 수 있다.

시작 방식 두 가지

자율 모드 · 기본값

학생 혼자 할 때

  • 첫 접속 시 보드 크기(4×4/6×6/9×9)와 시작 레벨을 직접 선택
  • 재방문 시 저장된 레벨·크기에서 바로 이어서 진행
  • 과제·자습·방과후 등 개별 학습 상황에 적합
지정 모드

교사가 일괄 지정할 때

  • 교사가 대시보드에서 학급 전체에 적용할 보드 크기·레벨을 한 번에 지정
  • 지정이 켜져 있는 동안 학생 화면의 선택 단계는 생략되고 바로 그 단계로 시작
  • 수업 중 다같이 같은 지점에서 출발해야 할 때 사용, 해제 시 자율 모드로 복귀

학습 사다리

LV. 0 · 규칙 알아보기인터랙티브 설명"가로줄·세로줄·박스 안에 같은 숫자가 올 수 없다"를 4×4 보드로 직접 눌러보며 익힘
LV. 1 · 크기 선택 & 연습4×4 · 6×6 · 9×9 중 연습 퍼즐 선택자율 모드면 학생이 선택, 지정 모드면 교사가 정한 크기로 진행 — 완주 경험 제공이 목적. 가장 작은 4×4부터 시작해도 되고, 자신 있으면 바로 큰 크기로 가도 됨
LV. 2 · 가이드 모드쉬움 난이도, 힌트 무제한오답 즉시 표시 + 후보 숫자 자동 표시로 추론 과정을 체득, 선택한 크기 그대로 유지
LV. 3 · 홀로서기쉬움 난이도, 힌트 3회 제한자동 후보 표시를 끄고 스스로 추론하도록 전환
LV. 4 · 사다리 완주9×9 난이도 탭으로 졸업v0.2부터 쉬움~전문가는 처음부터 모두 열려 있다. 사다리(Lv.1~3)는 '연습' 탭에서 원할 때 진행하는 학습 경로이고, 완주하면 기본 탭이 마지막으로 플레이한 난이도로 바뀐다
05

난이도 설계

표준 스도쿠 생성 관례에 따라 채워진 칸(단서) 수로 난이도를 구분한다. 숫자가 적을수록 후보 추론 단계가 늘어난다. 아래 기준은 9×9 기준이며, 4×4·6×6은 학습 사다리 Lv.0~3 전용 연습 크기로 별도 난이도 구분 없이 단서 수만 넉넉하게 둔다.

보통

어려움

전문가

06

누적 성장 · 레벨 시스템

풀이할 때마다 경험치(XP)가 쌓여 레벨이 오르고, 일정 레벨에 도달하면 칭호(뱃지)가 부여된다. 난이도가 높을수록, 실수·힌트가 적을수록 더 많은 XP를 지급해 '정확하게 푸는 것'도 보상한다.

Lv.1-3새싹
Lv.4-7숙련자
Lv.8-12고수
Lv.13+마스터
연속 참여🔥 스트릭 보너스

연속 참여일(스트릭)이 끊기지 않도록 하루 1회 접속만으로도 소량의 XP를 지급해, 매일 조금씩이라도 들여다보는 습관을 유도한다.

07

데이터 모델

기록은 두 종류로 나눈다. 세션 기록은 한 번의 풀이마다 쌓이는 로그, 누적 프로필은 학생별로 하나씩만 존재하며 방문할 때마다 갱신된다. 식별자는 로그인 대신 이름 + 학급 조합을 사용한다.

학생 화면은 접속 시 자신이 속한 학급의 isAssigned 값을 먼저 확인해, 켜져 있으면 선택 화면 없이 지정된 크기·단계로 바로 시작한다. ※ localStorage 기반 1차 버전에서는 같은 브라우저에서만 이어진다. 다른 기기에서도 이어가려면 서버 저장이 필요하다 — 뒤의 '기술 스택 제안' 참고.

08

학급별 랭킹 보드

랭킹은 '누가 가장 빨리 풀었는가'보다 꾸준함과 성장을 반영하도록 총 누적 XP를 기본 산정 기준으로 삼는다. 교사는 공개 범위(상위 3명 / 상위 50% / 전체)를 학급 사정에 맞게 설정할 수 있어, 하위권 학생이 공개로 인해 위축되지 않도록 배려한다.

난이도별 랭킹 (v0.2)

종합 랭킹과 별도로 난이도마다 보정 기록 순위를 둔다. 보정 기록 = 걸린 시간 + 실수 1회당 10초 + 힌트 1회당 30초이며 짧을수록 높은 순위다. 빠르면서도 정확하게 푸는 것을 보상하고, 표에는 "3:42 (실수 2·힌트 0)"처럼 근거를 함께 표시한다. 학생별 최고 기록 하나만 순위에 오르고, 교사의 공개 범위 설정이 똑같이 적용된다. 랭킹은 상단 메뉴 '🏆 랭킹', 게임 화면 옆 TOP 5, 결과 화면의 '이 난이도 반 n위'에서 볼 수 있다.

※ 학급 간 비교가 필요하면 '학급 평균 XP' 같은 반 단위 지표를 별도로 제공해, 개인 노출 없이도 담임 간 비교가 가능하게 한다.

09

퍼즐 생성 방식

① 백트래킹으로 완성된 정답판 하나를 무작위 생성 → ② 대칭 위치의 칸을 하나씩 비워가며 해가 유일한지 검증 → ③ 목표 난이도의 단서 수에 도달하면 멈춘다. 유일해 검증에 과도한 시간이 걸리면 직전 단계의 판을 채택해 생성 지연을 방지한다.
